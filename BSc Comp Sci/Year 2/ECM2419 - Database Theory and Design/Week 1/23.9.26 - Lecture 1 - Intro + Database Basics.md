#### Naive Database Example
The simplest form of a database is a single table, where columns are called fields or attributes and rows are called records; this terminology is consistent with other databases.

Using the example of a club member database, a record (row) would be a club member and an attribute (column) would be the club member's name, role, age, address, join date, etc.

However, this form of database introduces a lot of data duplication and potential inconsistencies when data is updated. This is why more advanced databases use multiple tables and specific links between them to improve usability and storage usage.


#### Database Definitions
A database is a collection of tables containing records and links between tables.

In simple terms, a **database (DB)** is an *organised collection of related data*.

A **database management system (DMS)** is a system that *manages* and *controls access* to the database.

A **database application** is a program that, at some point during its execution, *interacts* with a database to retrieve data.

A **database system** is a *collection* of *database applications* that interact with the database.
