
#### Recap of DB Storage Structure
The general DB storage structure is as follows:
 - Primary memory (RAM) - Where the DB operations are performed
 - Secondary storage (SSD/HDD) - Where the DB is actual stored
 - Stable storage - Where logs and DB backups are stored (different physical location than secondary storage)


#### DB Backup
A **backup** of a DB is a *copy of the DB* that is *made periodically* and stored in a *physically separate location*.

There are different types of backups you need to know about:
 - **Full** - A backup of the *entire DB* in one go
 - **Differential** - All *changes* since the *last full* backup
 - **Incremental** - All *changes* since the *last backup of any kind* (full or differential)
