
#### Arrays
Now, you might think arrays in functional programming is a lie, given there is no concept of a variable. However, Haskell does have arrays, but they aren't your usual arrays, to preserve the nature of functional programming.

There are two types of arrays: incremental and monolithic arrays.


#### Incremental Arrays
These are more of the traditional arrays, you *start with an empty array and make changes to copies of that array*. Now, Haskell does a weird thing, it stores the original array, then a *long series of updates* (functions to manipulate the array) that have been performed on the array. This means that whenever you want to query an array index, the program first takes the original array, and *applies the long list of updates* (functions) you made to it. This results in you using an array, but *with linked list performance*. Who wants that!


#### Monolithic Arrays
On the other hand, a monolithic array is where you create all elements of the array at array creation time, and are then never allowed to modify these elements. This preserves the functional programming idea of creating something and never changing it.

In Haskell, you create a monolithic array by first specifying a pair of inclusive bounds for the indices and then a list of 2-tuples (index-value pairs). Below is an example monolithic array in Haskell that generates a list of squares from 0 through 9.
```Haskell
import Data.Array

squares :: Array Int Int
squares
	= array (0,9) [(i,i*i) | i <- [0..9]]

main :: IO ()
main = print (squares)

-- OUTPUT ------------------------------------------------------------
array (0,9) [(0,0),(1,1),(2,4),(3,9),(4,16),(5,25),(6,36),(7,49),(8,64),(9,81)]
```

If you wanted to access a specific index in this array, you use the `!` operator: `squares ! 7` represents the value at index 7 in the array `squares`.
