#### Problem
$a$ and $b$ are the two friends' house number.
$\sum_{a+1}^{b-1}{i} = ab \text{, where a < b}$

```python
found = false
pair = (0,0)
for a in range(11,59):
	for b in range(a+1,60):
		sum = 0
		for i in range(a+1,b-1):
			sum += i
		
		if (a*b) == sum:
			found = true
			pair = (a,b)
print(pair[0])
print(pair[1])

-- OUTPUT ------------------------------------------------------------------------
14
35
```


#### The Turing Machine
The Turing Machine is a theoretical machine and sees computing as the manipulation of symbols on a tape.
The Turing Machine manifests itself in programming languages such as C++, Java, and Python.
The tape is theoretical, but its modern equivalent is RAM or secondary storage.


#### $\lambda$-Calculus
The $\lambda - \text{Calculas}$ computing method sees computing as the definition and evaluation of functions.
Like the Turing Machine, $\lambda$-calculus is theoretical, but manifests itself in programming languages such as LISP and Haskell.


#### Functional Programming
Variables are ONLY static, i.e. a constant - they never change.
This is the same for functions - with the same function $f$ and the same input $x$, the value of $f(x)$ will always be the same, no matter what.
Functional programs are mathematical objects; you can actually perform proofs on/using the programs themselves.
