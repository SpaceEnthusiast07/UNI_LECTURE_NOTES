
#### Tuples
Tuples are like lists, but are basically opposite, or orthogonal (perpendicular).

**Tuples** are of *fixed length*, are *enclosed within curved brackets*, and can have data of *different types*. Below is an example of a tuple.

```Haskell
(1,"Hello",4,"Tuples")
```

When using tuples, you have much for precise typing. This is because if you are writing 2D coordinates, the tuple only contains 2 values, so if you mist one out or add one, the compiler will catch that and give you an error.

You might wonder why we WANT a compiler error; well, they are much better than runtime errors, which is what would happen if you used Lists in this scenario.


#### Exercise: Unmerge Function
```Haskell
unmerge :: [(String,Int)] -> ([String],[Int])

unmerge []
    = ([],[])

unmerge ((a,b):abs)
    = (a:ps,b:qs)
    where
    (ps,qs) = unmerge abs

main :: IO ()
main = print(unmerge [("A",1),("B",2)])
```
