
#### Data Types
You define a new custom data type using the `data` keyword, followed by the data type's name. Below is a simple example:
```Haskell
data Colour
	= Red | Green | Blue
	deriving Show
```

The `|` symbol is used to separate the constructors of the data type. They are called constructors because they construct a new data type instance as such.

In the above example, each value/constructor doesn't have any parameters; hence, this is called an enumeration, but it is different from the Enums in a language such as Java. Below is an example where the data type constructors require parameters:
```Haskell
data Shape
	= Rectangle Float Float
	| Circle Float
	deriving (Eq, Show)
```

Here it makes sense to have parameters in the constructors because a `Rectangle` has a width and height, and a `Circle` has a radius. However, you may have noticed that we simply state the data type of the parameter, with no name. Therefore, you will never know whether width goes before height in the `Rectangle` constructor, nor will you ever know whether the float in the `Circle` constructor is for its radius, diameter, or circumference, but as programmers, we may have to make assumptions.

In both examples, I have used the `deriving` keyword alongside one or two other keywords that you may recognise. `Deriving` is used to tell the Haskell compiler to pre-generate some functions based on what you derive. For instance, with `Show`, this tells the Haskell compiler to pre-generate a function to print this custom data type to the screen, and for `Eq`, this tells the Haskell compiler that this data type can be compared for equality; i.e., is `RectangleA` equal to `CircleB`?


#### Using Custom Data Types
Now, you may be wondering how you would actually use a custom data type; well, below are some examples:
```Haskell
data Shape
	= Rectangle Float Float
	| Circle Float
	deriving (Eq, Show)

shapeArea :: Shape -> Float
shapeArea (Rectangle w h)
	= w * h
shapeArea (Circle r)
	= pi * r * r

main :: IO ()
main = print (Cirlce 42.0)

-- OUTPUT ------------------------------------------------------------
5541.7695
```

From this example, you can see that custom data type applications are very similar to function applications except, instead of computing a result, creates a value.
