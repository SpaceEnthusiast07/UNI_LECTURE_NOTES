
#### IF-THEN-ELSE
These statements are used to branch down different paths depending on the result of a Boolean expression.

They follow a very intuitive structure; if the result of a Boolean expression is true, a certain statement is executed, otherwise the statement in the else section is executed.

Example:
```Haskell
absolute :: (Num a, Ord a) => a -> a
absolute n
	= if n >= 0 then n else -n
```


#### CASE Statements
Case statements are effectively shorthand for lots of consecutive IF-THEN-ELSE statements.

Example:
```Haskell
piano :: Int -> String
piano n
	= case n of
	1 -> " Acoustic Grand Piano "
	2 -> " Bright Acoustic Piano "
	3 -> " Electric Grand Piano "
	4 -> "Honky - tonk Piano "
	5 -> " Electric Piano 1"
	6 -> " Electric Piano 2"
	7 -> " Harpsichord "
	8 -> " Clavinet "
```
