#### CASE Statements



#### Exercise 1
```Haskell
ph :: (Num a, Ord a) => a -> String
ph n
    = if n < 7 then "acidic" else if n > 7 then "alkaline" else "neutral"

main :: IO ()
main = print (ph 12)
```


#### Exercise 2
```Haskell
beaufort :: Int -> String
beaufort n
    = case n of
    1  -> "Calm"
    2  -> "Light air"
    3  -> "Light breeze"
    4  -> "Gental breeze"
    5  -> "Moderate breeze"
    6  -> "Fresh breeze"
    7  -> "Strong breeze"
    8  -> "Moderate gale"
    9  -> "Gale"
    10 -> "Strong gale"
    11 -> "Violent storm"
    12 -> "Hurricane"

main :: IO ()
main = print (beaufort 8)
```
