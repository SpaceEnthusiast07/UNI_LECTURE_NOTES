
#### Teaser
“I have a couple of subtraction problems for you”, George told Martha. Look:
N1 − N2 = N3 and N3 − N4 = N5 . Can you solve them if I tell you that N1 , N3
and N5 are all three-digit whole numbers whose sum is less than 2000, the same
three non-zero digits appearing in all three numbers but no digit being repeated
within any of those numbers? N2 and N4 are both two-digit whole numbers using
two of the three digits mentioned above, and the first digit of N1 is not equal to
the first digit of N2.

What is N1?


#### 1 Understanding
 - $N1 - N2 = N3$
 - $N3 - N4 = N5$
 - $N1 + N3 + N5 < 2000$
 - $N1, N3, N5$ are 3-digit whole numbers which all use some variation of the same 3 digits
 - $N2$ and $N4$ are 2-digit whole numbers which use 2 of the 3 digits above
 - First digit of $N1$ is not equal to that of $N2$


#### 2.1 Numbers
Generates all 3-digit numbers with no repeating digits.
```Haskell
import Data.List((\\))

numbers :: [[Int]]
numbers
    = [[read [d1], read [d2], read [d3]]
    | d1 <- "123456789"
    , d2 <- "123456789" \\ [d1]
    , d3 <- "123456789" \\ [d1,d2]
    ]
```


#### 2.2 Permutations of a 3-Digit Number
Given a String or list of Chars representing a 3 digit number, return the permutations of this 3 digit number.
```Haskell
import Data.List((\\))

permutations3of3 :: [Char] -> [String]
permutations3of3 a
    = [[x,y,z]
    | x <- a
    , y <- a \\ [x]
    , z <- a \\ [x,y]
    ]
```


#### 2.3 Permutations of a 3-Digit Number to get a 2-Digit Number
Given a 3-digit number as a String (list of Chars) and returns the permutations of length 2; i.e., 2-digit numbers.
```Haskell
import Data.List((\\))

permutations2of3 :: [Char] -> [String]
permutations2of3 a
    = [[x,y]
    | x <- a
    , y <- a \\ [x]
    ]
```


#### Final Program
```Haskell
import Data.List((\\))

numbers :: [String]
numbers
    = [[d1, d2, d3]
    | d1 <- "123456789"
    , d2 <- "123456789" \\ [d1]
    , d3 <- "123456789" \\ [d1,d2]
    ]

permutations3of3 :: [Char] -> [String]
permutations3of3 a
    = [[x,y,z]
    | x <- a
    , y <- a \\ [x]
    , z <- a \\ [x,y]
    ]

permutations2of3 :: [Char] -> [String]
permutations2of3 a
    = [[x,y]
    | x <- a
    , y <- a \\ [x]
    ]

generator :: [(Int,Int,Int,Int,Int)]
generator
    = [(read n1, read n2, read n3, read n4, read n5)
    | n1 <- numbers
    , n2 <- permutations2of3 n1
    , n3 <- permutations3of3 n1 \\ [n1]
    , n4 <- (permutations2of3 n1) \\ [n2]
    , n5 <- (permutations3of3 n1) \\ [n1,n3]
    , head n1 /= head n2
    ]

selector :: (Int,Int,Int,Int,Int) -> Bool
selector (n1,n2,n3,n4,n5)
    = n1 - n2 == n3
    && n3 - n4 == n5
    && n1 + n3 + n5 < 2000


main :: IO ()
main = print (filter selector generator)


-- OUTPUT ------------------------------------------------------------------------
[(594,45,549,54,495)]
```

Therefore, $N1 = 594$.
