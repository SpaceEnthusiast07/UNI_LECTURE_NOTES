
#### Polymorphic Types



```Haskell
sort :: Ord a => [a] -> [a]
sort (x:xs)
	= insert x (sort xs)
sort []
	= []
```

Class Type constraints propagate upwards the function



```Haskell
decreasing :: Ord a => [a] -> Bool
decreasing (x1:x2:xs)
	| x1 > x2 = decreasing (x2:xs)
	| otherwise = False
decreasing [x]
	= True
```

```Haskell
decreasing :: Ord a => [a] -> Bool
decreasing xs
	= increasing (reverse xs)
```
