
#### Higher Order Functions
A **higher order function** is a function that can either take a *function as an argument* or can *return a function*.

The reason this passing around of functions themselves is because Haskell treats functions like regular data.

The benefits of these functions include:
 - *Reusability* - recurring patterns can be abstracted into a single function
 - *Maintainability* - improvements to the function automatically affect all users
 - *Readability* - the resulting function itself is more concise

The function `twice` is a basic example of a higher order function; it takes in a function and a piece of data, and applies the function to the data twice.
```Haskell
twice :: (a -> a) -> a -> a
twice f x
	= f (f x)

increment :: Int -> Int
increment x
	= x + 1

main :: IO ()
main = print (twice increment 4)

-- OUTPUT ------------------------------------------------------------
6
```

You may notice a few things different about the function type definition in particular. When defining the type for the function parameter itself, that function's type should go in curved brackets. We use the place holder `a` here to allow for functions of different types.


#### Expected Built-In Functions
There are a few built-in higher order functions that you need to be aware of:

**`filter`**
```Haskell
filter :: (a -> Bool) -> [a] -> [a]
filter p (x:xs)
	| p x       = x : filter p xs
	| otherwise =     filter p xs
filter p []
	= []
```
The `filter` function takes in a function, often called the `selector`, and a list of items. It them applies the function to each item in the provided list, and returns a list of the elements for which the output of the provided function, or `selector`, is `True`, that's what the function guard clauses are for.

**`map`**
```Haskell
map :: (a -> b) -> [a] -> [b]
map f (x:xs)
	= f x : map f xs
map f []
	= []
```
The `map` function is very similar to `filter`, but it simply applies the provided function to all elements in the provided list and returns a list containing all results, no matter what they are.

**`foldr`**
```Haskell
foldr :: (a -> b -> b) -> b -> [a] -> b
foldr f z (x:xs)
	= f x (foldr f z xs)
foldr f z []
	= z
```
The `foldr` function "folds" a list of items up, starting from the right-hand side. It does this by applying the provided function `f` to each pair of elements starting at the right. This function could be the `or` operation or the addition operation.
You may wonder what `z` is; well, it is simply a placeholder or "default" value for when the list to fold is empty.
