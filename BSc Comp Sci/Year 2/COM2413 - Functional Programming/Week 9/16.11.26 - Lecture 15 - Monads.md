
#### Monads
A **monad** is a *design pattern* in functional programming that is used to structure computations as a *sequence of steps*.

Yes, a sequence of steps, you heard that write!

Oh, and its pronounced "mo-nads", just in case you are one of those minority who doesn't intuitively know how to pronounce it! 🤣

In this lecture, we are going to use monads to implement exception handling, and in the next lecture we will go through how to implement input and output in functional programming.

However, we need to introduce a few more concepts first.


#### The Maybe Type
In traditional programming, if a function cannot return what you want, it normally returns `Null` or `-1`, for instance. But, in functional programming we don't want to do this, so we return `Nothing` or `Just` some value.
