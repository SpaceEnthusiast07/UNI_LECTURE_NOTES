
#### Reflection
**Reflection** is a concept, implemented through the `java.lang.reflect` API, allowing *one object* to *examine* the entire *contents of a class*, whether that be its own class or another class.

Reflection completely *breaks encapsulation*, allowing an object to examine all fields and methods, *regardless of access modifiers*; i.e., allows access to private fields and methods.

To be able to examine a class's structure, you must use the classes provided in the `java.lang.reflect` package.

`java.lang.Class` is used to represent a class itself, and provides methods to query the properties of a class. At run time, the JVM instantiates a `java.lang.Class` instance for each class.

Every class that is created has an immutable instance of `java.lang.Class` instantiated for it by the JVM. This `java.lang.Class` instance provides the methods to query all the properties of a class.


#### Using `java.lang.Class`
There are two ways for getting the class of an object or primitive type: `.getClass()` or `.class`.

`.getClass()`
This is an inherited method from the `Object` class, and is used to get the class from an instance of a class; e.g., `Circle c = new Circle();` then use `Class circleClass = c.getClass();`.

`.class`
However, if you don't have access to an instance, you can use `.class` on the end of the class name itself. Therefore, this also works on primitive types as well; e.g., `Class circleClass = Circle.class;` or `Class floatClass = float.class`;

You can also get the class of a class by specifying its *fully qualified* name (its full package name) using `Class.forName()`; e.g., `Class stringClass = Class.forName("java.lang.String");`.
