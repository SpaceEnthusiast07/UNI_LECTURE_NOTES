#### Exercise 2: Switching Users
Log in as different users: alice, bob, and eve.

Command: `su user_name`
 - `su` stands for *switch user* and allows you to switch users, and prompts you for a password, if user has one.
 - `user_name` is the name of the user you wish to switch to.
 - This command switches to the desired user, but you remain in the directory where you called the command from.

Command: `su - user_name`
 - By adding the `-`, you then change directory into the home directory of the user you have switched to.


#### Exercise 3: Exploring Groups
Question Brief:

After exploring the group structure, create a directory that `bob` and `eve` can use to share files confidentially.*

Each file on a Linux system is *owned* by a user and a group.

You can use the long version of the `ls` command, specifically `ls -l`, to see the access permissions for a file on the system.

Example use of `ls -l`:
![[Pasted image 20260924145643.png|341]]

This section `-rw-r--r--` informs you of the access permissions the owning user, owning group, and non owning user has.
 - The first character tells you what type of file it is. `-` means standard file, and `d` means directory.
 - The permissions are then grouped into groups of 3 characters, where the first is the owning user, the second being the owning group, and the third being non owning users.
 - The options for the permission section are `r` - read, `w` - write, and `x` - execute.

The `/etc` directory contains a plain text file called `group`, which outlines each group on the system. Each line is a group declaration in a specific format. The following diagram illustrates the format of the group file:
![[Pasted image 20260924151944.png|375]]

You might notice that the password field is populated with an `x`, this means that the password is not stored in this plain text file, for security reasons. However, the password is stored in what is known as a shadow file, specifically `/etc/gshadow` - for group shadow. A shadow file is a secure system file in linux that is used to store passwords.

Also within the `/etc/` directory, you have a file called `passwd`. This file keeps track of all the registered users on the system and different configurations for that user. Yet again, the password field is marked with an `x`, meaning the password is stored in a secure shadow file, specifically `/etc/shadow` this time.

Finally, to create a directory that bob and eve can use to share files confidentially, you need to create a directory with the owning group being a group with only bob and eve, namely `team02`.

These are the commands to create such directory in the current working directory:
```zsh
# Create the necessary directory
mkdir Team02SecureFolder

# Change the owning group
sudo chgrp team02 Team02SecureFolder

# Ensure the owning user is either bob or eve
sudo chown bob Team02SecureFolder
```

This results in the directory `Team02SecureFolder` only being accessible by `bob` (the owner) and anyone in the group `team02` (which is `bob` and `eve`).
