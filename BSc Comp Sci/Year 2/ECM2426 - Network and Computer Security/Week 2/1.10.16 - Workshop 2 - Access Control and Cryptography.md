
#### Exercise 1: Adding a new user
To add a new user to a Linux system, you must use the `adduser` command; however, you might notice that you get the error message `Permission denied` or `Command not found`. This is because the root user only has the power/permission to add new users to the system. Therefore, you must prefix the `adduser` command with the `sudo` command to perform the `adduser` operation with root user privileges. Below is an example usage of the `adduser` command:
```Zsh
sudo adduser bob
```

You might wonder what `sudo` sands for and how it relates to the `root` user; `sudo` stands for *super-user do*.

>[!Warning] Use `sudo` wisely as it is a massive security risk if not used correctly.

Still on the topic of the `adduser` command, when you add a new user, the command also creates a new group with the name of the user. You may have noticed this when using the `ls -l` command; you can see that the name of the owning user and owning group both have the same name.

#### Exercise 4: Access Control Lists
The aim of this question is to show you that more access controls are hidden beyond the simple 3 sections you get when using the command `ls -l`.
![[Pasted image 20261001163100.png|147]]

In the example in the workshop VM, using the `ls -l` command within the user `bob`'s home directory shows a directory called `write_test` which has permissions `rwx` for the owning user and group, but only `r-x` for others. The owner and group are called `www-data`, but using the `groups` command reveals that `bob` isn't part of the `www-data` group. So, how can `bob` run the command `echo "Hello world" > hello.txt` within this `write_test` directory?
![[Pasted image 20261001163415.png|426]]

Well, there is a sneaky little `+` symbol at the end of the simplified access control list in the `ls -l` commands output. This `+` indicates that more access controls are in place than the ones displayed here.
![[Pasted image 20261001163218.png|204]]

To access these hidden access controls, you must use the command `getfacl`. It sounds scary and complicated, but it simply stands for `get-file-access-control-list`. Running this command `getfacl write_test` reveals that there is an extra access control permission explicitly stating that the user `bob` has `rwx` permissions on this directory.
![[Pasted image 20261001163513.png|277]]

You can then use the `setfacl` command to update this file, either to remove `bob`'s personal permissions or add a personal permission for another user.

This question provides an encrypted message using the substitution method, where only the 26 letters of the alphabet have been substituted for emojis and not any symbols or numbers.

Since this is a substitution cypher, you must perform a frequency attack, which involves looking up the frequency of letters in texts. From this you can run the provided Python program to analyse the text and produce an output detailing the frequency of each emoji. You then use the frequency of letters, such as E being the most frequent letter, to use the "Find and Replace" function in the text editor to replace certain emojis with your predicted letter.
