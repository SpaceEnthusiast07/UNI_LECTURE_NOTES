
#### Exercise 1: Adding a new user
To add a new user to a Linux system, you must use the `adduser` command; however, you might notice that you get the error message `Permission denied` or `Command not found`. This is because the root user only has the power/permission to add new users to the system. Therefore, you must prefix the `adduser` command with the `sudo` command to perform the `adduser` operation with root user privileges. Below is an example usage of the `adduser` command:
```Zsh
sudo adduser bob
```

You might wonder what `sudo` sands for and how it relates to the `root` user; `sudo` stands for *super-user do*.

>[!Warning] Use `sudo` wisely as it is a massive security risk if not used correctly.

Still on the topic of the `adduser` command, when you add a new user, the command also creates a new group with the name of the user. You may have noticed this when using the `ls -l` command; you can see that the name of the owning user and owning group both have the same name.
