
#### Dynamic Application Security Testing (DAST)
This form of security testing is called *dynamic* because you are *analysing the system in an executing state*, as a pose to static where you analyse the source code of the system.


#### OWASP ZAP
ZAP, which stands for Zed Attack Proxy, is an easy to use penetration tool for finding vulnerabilities in web applications; i.e., a dynamic security testing tool.
