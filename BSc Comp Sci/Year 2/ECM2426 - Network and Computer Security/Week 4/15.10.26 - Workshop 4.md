

#### 1. NMAP - Scanning Networks
**NMAP (Network Mapper)** is a port scanner tool which explores remote computers and identifies their open ports, the services they run, and the software version they use.

NMAP uses IP packets in novel ways to:
 - Determine which hosts are available on a network
 - What services (app name and version) they are offering
 - What Operating System (name and version) they are running
 - What type of packet filters/firewalls are in use
 - and more!

The structure of the NMAP command is:
```
nmap [arguments] [domain/IP]
```

You have different arguments:
 - `-A` is used to enable OS name and version detection, script running, and traceroute.
 - `-T4` is used to enable faster execution.
