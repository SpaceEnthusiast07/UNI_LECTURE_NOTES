
#### Security Testing
You can either test the source code or a running version.

**Source Code**
Manual - *Manual code review*
Automatic - *Static Application Security Testing (SAST)*

**Running Version**
Manual - *Penetration testing*
Automatic - *Dynamic Application Security Testing (DAST)*

SAST Approach - Injection
 - SQL injection
 - JS - Cross Site Scripting (XSS)
 - OS level
